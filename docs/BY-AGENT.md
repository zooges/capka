# B&Y AGENT 使用说明

**B&Y AGENT** 是上海邦信阳律师事务所的团队 AI 助手。你可以在电脑或手机上打开它，用自然语言处理合同、资料、表格和日常文书类工作；系统会在隔离环境中完成具体操作，并把结果交还给你。

- 地址：<https://agent.boss-young.com>
- 登录方式：建议使用**飞书账号**（与所内身份一致）

生成内容请由承办律师结合案件事实与适用法律复核，不构成自动法律意见。

## 三种使用方式

| 方式 | 适合谁 | 说明 |
|------|--------|------|
| [飞书工作台](#一飞书登录工作台) | 日常办公、手机与电脑 | 在飞书里打开，免单独记网址 |
| [手机 App](#二手机-app-安装) | 外出、希望更像原生 App | TestFlight / 企业分发安装「邦信阳」 |
| [网页登录](#三网页登录) | 浏览器快速使用 | 打开网址即可，支持飞书扫码/授权登录 |

三种方式连的是同一套服务，账号与对话数据互通（以管理员配置为准）。

---

## 一、飞书登录（工作台）

适合：已安装飞书、希望从工作台一键进入。

1. 打开 **飞书**（电脑版或手机版均可）。
2. 进入本所工作台，找到应用 **B&Y AGENT**（或管理员公布的应用名称）。
3. 点击打开；若提示授权，选择同意。
4. 首次使用若需选择账号或完成绑定，按页面提示操作即可。

**说明**

- 工作台入口由管理员在飞书开放平台配置；若看不到应用，请联系管理员开通可用范围。
- 在飞书内置浏览器中登录时，一般会直接完成授权，无需再跳转到外部 App。

---

## 二、手机 App 安装

适合：希望在主屏幕使用独立 App、推送与手势体验更好。

当前 iOS 客户端显示名为 **邦信阳**（App Store Connect 应用名可能为 B&Y AGENT），通过 Apple TestFlight 安装（具体以管理员通知为准）。

### 安装步骤（iOS）

1. 在 iPhone / iPad 上安装 Apple **TestFlight**（App Store 搜索即可）。
2. 打开管理员发给你的 **TestFlight 邀请链接**，或在邮件中接受邀请。
3. 在 TestFlight 中找到 **邦信阳** / **B&Y AGENT**，点 **安装**。
4. 打开 App → 选择 **使用飞书登录** → 跳转飞书授权 → 返回 App 即可使用。

### 使用提示

- App 打开的地址为：<https://agent.boss-young.com>
- 需已安装飞书，并使用本所有权账号登录飞书。
- 若提示无法打开页面，请确认手机能访问所内网络 / VPN（以 IT 要求为准），或联系管理员检查域名与证书。

Android 若另行提供安装包或企业应用市场入口，以管理员最新通知为准。

## 三、网页登录

适合：电脑浏览器、临时使用、或不想安装 App。

1. 用浏览器打开：<https://agent.boss-young.com>
2. 在登录页选择 **飞书登录**（推荐）。
3. 按提示在飞书中确认授权；授权成功后会回到 B&Y AGENT。
4. 若管理员开放了账号密码注册/登录，也可按页面选项使用（非默认推荐）。

**建议**

- 使用 Chrome、Edge 或 Safari 等现代浏览器。
- 可将该网址保存为书签，或固定到浏览器标签页。
- 公共电脑使用完毕后请退出登录。

## 常见问题

**打不开 https://agent.boss-young.com？**  
检查网络是否可达（办公室网络 / VPN），或联系 IT / 管理员确认域名解析与证书。

**飞书登录失败？**  
确认飞书已登录本所账号；仍失败时把报错截图发给管理员（可能是应用未对你的部门开放，或回调地址未配置）。

**App 里点了飞书登录没有反应？**  
确认已安装飞书客户端；若刚安装 App，可完全退出后重试一次。

**网页和 App 是同一账号吗？**  
是。使用同一飞书身份登录即可看到同一套权限下的内容（具体以管理员策略为准）。
